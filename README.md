# Task Manager Web Application

A simple Task Management web application built using **Flask** and **MySQL**.  
This project supports basic CRUD operations where users can add, view, and delete tasks.

## Features
- Add new tasks with title, description, and status
- View all tasks
- Delete tasks
- Persistent data storage using MySQL

## Tech Stack
- Frontend: HTML, CSS
- Backend: Python (Flask)
- Database: MySQL
